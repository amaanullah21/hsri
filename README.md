# Hafzan’s Stagflation Resilience Index (HSRI) Calculator

A web-based analytical tool designed to quantify a nation's capacity to withstand stagflationary pressures. This tool implements the formula proposed in the paper: **"Introducing The Hafzan’s Stagflation Resilience Index (HSRI): A Composite Measure for Macroeconomic Adaptability"** by **Amaanullah Bhatti (Hafzan Osmanoğlu)**.

## 📖 Overview

Stagflation—characterized by stagnant economic growth, high unemployment, and high inflation—presents a unique challenge to traditional monetary and fiscal policy. The **HSRI** provides a unified metric to evaluate economic adaptability by balancing growth-oriented drivers against macroeconomic stressors.

### The Formula
The index is calculated as:

$$HSRI = \frac{\text{Productivity Growth} \times \text{Money Velocity}}{\text{Unemployment Rate} \times \text{Inflation Rate}}$$

*   **Numerator (Drivers):** Represent economic efficiency and the dynamism of monetary circulation.
*   **Denominator (Stressors):** Represent the core pains of stagflation that drain economic resilience.

## 🚀 Features

-   **Interactive Calculation:** Real-time processing of macroeconomic indicators.
-   **Intelligent Benchmarking:** Color-coded results that classify an economy from "Critical" to "Elite."
-   **Data Validation:** Logic to handle edge cases and identify potential "overheating" outliers.
-   **Responsive Design:** Fully functional on desktop, tablet, and mobile devices.

## 📊 Interpretation & Ranges

| HSRI Range | Classification | Economic Meaning |
| :--- | :--- | :--- |
| **< 0.10** | 🔴 Critical | Active stagflation; no buffer against shocks. |
| **0.10 – 0.50** | 🟠 Vulnerable | Fragile state; growth barely keeping pace with stressors. |
| **0.50 – 2.00** | 🟢 Resilient | Healthy adaptability; stable productive foundations. |
| **2.00 – 5.00** | 🔵 Elite | Exceptional resilience and high adaptability. |
| **> 5.00** | 🟣 Outlier | Potential "Overheating" or unsustainable monetary velocity. |
